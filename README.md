# Desafio de Arquitetura AWS - DIO 🚀

Este projeto faz parte do desafio da **Digital Innovation One (DIO)** para consolidar conhecimentos em **AWS EC2, S3 e Lambda**.

## 📌 Objetivo
Criar um **diagrama de arquitetura em nuvem** usando [draw.io](https://www.drawio.com), representando o fluxo de dados entre serviços AWS.

## 🛠️ Arquitetura
- **Amazon S3** → Armazena os arquivos enviados pelo usuário.
- **AWS Lambda** → Processa os arquivos automaticamente quando chegam no S3.
- **Amazon DynamoDB** → Armazena metadados e resultados do processamento.
- **Amazon EC2** → Servidores de apoio que podem ser utilizados para processamento adicional ou suporte à aplicação.
